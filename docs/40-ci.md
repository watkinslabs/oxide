Local gates own merge verification. GitHub Actions is an on-demand diagnostic surface, not a required merge wall. No soak gating or duration-based exit criterion.

## 1

1. `.github/workflows/pr.yml` has only `workflow_dispatch`; pull requests and pushes do not start hosted builds.
2. `main` has no required GitHub status contexts; a PR never waits for a hosted kernel matrix.
3. `.githooks/pre-push` runs the warning control, lint ratchet, isolated host and test-target builds, both-architecture feature checks, and linked-ELF frame, task-stack, and hard-IRQ gates for kernel-visible changes.
4. Boot-visible branches run paired local KVM smoke before push; every merge runs paired local KVM smoke per `CLAUDE.md`.
5. Full spec-lint, workspace tests, Miri, Loom, clippy, dependency, coverage, benchmark, and acceptance automation remain open infrastructure work unless a local gate owns them.

## 2

| Gate | Owner | Contract |
|---|---|---|
| warning control | pre-push | the wrapper's red warning control fails and clean control passes |
| `lint-ratchet` | every push | spec-lint findings cannot grow per `(crate, rule)` |
| `hosted-gate` | kernel-visible push | 103 workspace crates type-check independently with warnings denied |
| `test-build-gate` | kernel-visible push | 103 crates build their test targets independently with warnings denied |
| `feature-gate` | kernel-visible push | x86_64 and aarch64 compile with the full routine debug-feature set |
| frame/task/IRQ stack gates | kernel-visible push | both linked release kernels remain inside their three stack budgets |
| paired smoke | manual before boot-visible push; mandatory after merge | both architectures reach userspace and answer serial RX |

Feature-branch pushes skip the hook's duplicate smoke because the developer runs the paired smoke once after all other gates are green. Documentation-only and workflow-only pushes run the lint ratchet and skip kernel builds.

## 3

No release workflow exists. A release still requires both architecture gates and `43§2` acceptance on the tagged commit; automation is open work.

Artifact contract: `(commit, arch, sha256s of kernel + rootfs, acceptance-binary list with exit codes)`.

## 4

No benchmark workflow or `bench-history/main` store exists. The required design is per-commit median+p99 cycles, pruned to 90 days plus version tags.

`tools/perfrunner/` supplies cycle-accurate timing (`rdtsc`/`cntvct`), 1000 iterations per operation, five trials.

## 5

No digest-pinned build image or image workflow exists. Manual GitHub jobs install the pinned Rust toolchain directly on `ubuntu-latest`.

The future image requires the pinned Rust toolchain, both QEMU targets, firmware, image tools, `cargo-deny`, coverage tooling, fuzz tooling, git, curl, and make.

## 6

| File | Trigger | Action |
|---|---|---|
| `.github/workflows/pr.yml` | manual dispatch | optional hosted diagnostics; never gates merge |

## 7

- Required verification: local development host with KVM; both architectures build and boot in parallel when uncontended.
- Optional diagnostics: GitHub-hosted `ubuntu-latest`; x86_64 builds natively and aarch64 cross-compiles when manually dispatched.

## 8

- A new spec-lint finding over the ratchet baseline fails push.
- A compiler warning in a reached crate or kernel configuration fails push.
- An independently broken crate or test target fails push.
- A linked release frame, task-stack path, or hard-IRQ path over budget fails push.
- A boot-visible merge that does not reach userspace and answer serial RX on both architectures fails post-merge verification.

## 9

- A local gate failure blocks push until fixed; bypass variables are exceptional diagnostics, not routine merge policy.
- Concurrent QEMU processes invalidate timing and boot conclusions; check the exact process list before smoke.
- Manual GitHub diagnostics may be red or absent without delaying a locally verified merge.

## 10

Use the local command's exit status and retained smoke log for the exact worktree. Manual Actions logs are supplemental evidence only.
