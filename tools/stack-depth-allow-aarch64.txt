# Static call paths at or over the stack-depth ceiling when the gate landed
# (aarch64). Tolerated at or below the recorded budget ONLY — a new or deeper
# path FAILS. Each block states why that family is legitimately deep; the
# gate refuses an entry that is not under a reason block, and fails on an
# entry naming a path that is no longer in the kernel.
#
# Entries are DEMANGLED paths (B1632), which survive a rebuild with a different
# feature set; a mangled symbol is still accepted and normalised.
#
# Burn this down. Regenerate with:
#   make stack-gate-baseline-arm
#
# EMPTY, and it stays that way. B1618 removed the network TX/RX/socket-control
# family; B1620 removed fork/clone; B1621 took the last two — `oxide_svc_save_block`
# and `oxide_syscall_dispatch`, the roots of the whole syscall fan-out — under
# the ceiling by boxing the transmit job the dispatch loop moves by value.
# Every aarch64 path the linker can see is now under 13000 B with the
# schedule() blocking tail already charged, so ANY entry added here is a
# regression to fix, not a budget to record.
