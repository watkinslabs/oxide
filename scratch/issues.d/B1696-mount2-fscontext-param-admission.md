# B1696 — `mount(2)` parameter admission

Closes the curated ledger row: **"`mount(2)` never builds an `FsContext`, so a
fix confined to the parameter path would not fix real mounts."** (`OPEN | high`,
owner B1686). `dispatch_mount` now builds an `FsContext`, parses `source`, runs
`parse_monolithic_mount_data`, checks `mount_capable`, then `vfs_get_tree` — the
reference's `do_new_mount` order — so both entry points reach one verdict.
