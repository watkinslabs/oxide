# F791-rework-fs-landlock-key-rows

Lane: work the `NEEDS-REWORK` rows in `scratch/syscall-compliance-matrix.md` outside
the socket families — `431 fsconfig`, `432 fsmount`, `444/445/446 landlock_*`,
`249 request_key`, `250 keyctl`. Each row's recorded GAP was re-verified against the
code rather than trusted.

**Headline: five of the seven recorded GAPs were STALE — they described defects that
later work had already closed, and two of them were the only stated reason the row was
held open.** A GAP text is not evidence; it is a claim with an expiry date. The rows
below record what is true now.

Code delivered on this branch: Landlock ABI 8 → 10 (`ACCESS_FS_RESOLVE_UNIX`, the two
UDP port rights, `LANDLOCK_ADD_RULE_QUIET` and the three `quiet_*` ruleset masks), plus
four semantic divergences closed — same-thread-group signalling, the net-check
short-circuit, the invented family-mismatch `EINVAL`, and the user-namespace scoping of
the `landlock_restrict_self` capability test. Landlock hosted tests 89 → 106.

**No row was promoted to `IMPL`.** Every row still has at least one named, verified
defect; the reasons are in the matrix notes and in the rows below.
