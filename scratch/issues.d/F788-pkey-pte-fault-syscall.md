# F788-pkey-pte-fault-syscall

| Status | Sev | Issue | Evidence | Owner |
|---|---|---|---|---|
| OPEN | high | **I reported a fault-class bug on aarch64 that does not exist, and it was repeated back to me as an instruction — retracting it here so nobody implements it.** I claimed permission-overlay faults arrive with DFSC `0x30..0x33` and fall into `abort()`'s `_` arm as `SI_KERNEL`. Wrong: `0x30..0x33` are **EC** values (breakpoint / software-step), not DFSC values — I conflated the two fields. A permission-overlay abort has **no fault-status code of its own**; it arrives as an ordinary permission fault (DFSC `0x0c..0x0f`), which `abort()` already classifies correctly as `SEGV_ACCERR` and `classify_arm_abort` already treats as `Protection`. There is no independent correctness bug here. `ESR_ELx.ISS2.Overlay` (bit 6) is a HINT only and must not drive classification: it can be set spuriously (rights register updated without an `isb` on context switch) and clear when a key violation should still be reported (no page mapped yet but the rights already forbid the access). The verdict has to come from comparing the live rights register against the VMA's key. Pinned by `an_overlay_flagged_permission_fault_classifies_as_a_permission_fault`. | F788; `ESR_ELx_Overlay_SHIFT` is 6 in the reference, and `fault_from_pkey`'s comment states both failure modes explicitly. | — |
| OPEN | med | `classify_arm_abort` maps every DFSC outside `0x04..=0x07` to `Protection{access}`, including external aborts (`0x10`), ECC/parity (`0x18`) and alignment faults (`0x21`). Those are then handed to the demand-paging resolver, which cannot fix them, before falling through to the signal path that classifies them correctly. Not a wrong answer reaching userspace — the eventual signal is right — but it is a wasted resolve attempt on a fault class that is never resolvable, and it is the function that would need an explicit arm if a future fault class must NOT be treated as COW-able. | F788; `mm-pmm/src/user_as/teardown.rs` `classify_arm_abort`. | — |
