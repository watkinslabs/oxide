by whoever folds this drop file:

- The row reading `Fast-open family (TCP_FASTOPEN, _KEY, _NO_COOKIE) stored with nothing

  and test-pinned (matches a zero enable bit).` — the enable bit is no longer zero. The
  sysctl exists, its compiled default carries the client bit, and `TCP_FASTOPEN_CONNECT`

  accept queue instead of two loose option values, and `listen` sizes that queue by
  itself when the namespace asked it to. What is still true: no handshake consumes any
  of it (row above).

  unchanged in substance; the codec's consumer is piece 2.
