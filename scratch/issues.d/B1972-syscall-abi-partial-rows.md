`72 fcntl`, `101 ptrace`, `230 clock_nanosleep`, `324 membarrier`,
`335 uretprobe`, `336 uprobe`, `471 rseq_slice_yield`). Of 17 specific gaps the
matrix claimed, 10 were already closed or vacuous. The rows below are the

## Stale claims corrected (no work owed)

| Row | Claim | Finding |
|---|---|---|
| 16 | filesystem-specific DAX support outstanding | Vacuous. The reference's ext4 accepts the DAX attr and returns success even with no dax-capable device — the device capability only gates whether the inode is actually wired for DAX, never the errno. Oxide returns success and does not persist the bit, the same observable outcome. Oxide has no dax-capable device and cannot have one. |
| 16 | filesystem-specific remap backends outstanding | Vacuous. The reference's ext4 implements no remap callback at all, so a clone on ext4 is EOPNOTSUPP upstream. Oxide returns EOPNOTSUPP by the same absent-callback route. No oxide filesystem advertises remap upstream either. |
| 16 | remaining driver/file-specific ioctl families | No concrete gap found. `sys_ioctl` is a single dispatcher covering every fd kind oxide has, and the fallback returns ENOTTY, which is the reference's answer for an fd kind with no ioctl callback. |
| 16 | (implied) a second ioctl dispatch table | Only one `sys_ioctl`; the per-fd-kind `match req` sites are handlers called from it, not competing tables. |
| 72 | no blocking lease break | Closed. `crates/kernel/syscalls/src/open_common.rs:192-216` checks conflict, signals the holder, returns EWOULDBLOCK for the non-blocking path, otherwise waits to a deadline checking for signals, and force-revokes only on timeout. Residual nit: the interrupted arm returns EINTR directly rather than the restart sentinel the lock path uses. |
| 72 | `F_SETLKW` parks and never returns | Closed. `crates/kernel/fs/src/posix_lock.rs:141-164` handles deadlock (EDEADLK) and returns the restart sentinel when a signal interrupts the wait. |
| 101 | PEEKSIGINFO, GET/SET_SYSCALL_INFO, SECCOMP_GET_FILTER/METADATA, GET_RSEQ_CONFIGURATION, SYSCALL_USER_DISPATCH_CONFIG all EIO | Closed. All are implemented in `crates/kernel/syscalls/src/101_ptrace/info.rs`. GETFDPIC remains EIO, which is correct — it exists only for a memory model neither target architecture uses. |
| 101 | no hardware debug registers | Closed. x86 debug registers drive a real validation ladder, context-switch install and trap classifier; aarch64 goes through the hardware-breakpoint/watchpoint regsets. |
| 101 | `PTRACE_EVENT_*` fork/clone/exec stops not generated | Closed. Generated from the clone path (fork/vfork/clone plus vfork-done) and the exec path. |
| 101 | ptrace scope sysctl not consulted | Closed. Consulted on both the traceme and the attach/seize routes. |
| 101 | 37 hosted tests | Stale count: 98. |
| 101 | arm64 step-over-a-hit re-arm latches missing | Mis-scoped — see the `toggle_enables` row above. Not a ptrace gap. |
| 230 | interrupted `TIMER_ABSTIME` returns 0 where the reference returns EINTR; ENOSYS on 2 of 3 boots | Unreproduced, and the source claim reports its own instability. The absolute arm returns the no-restart-handler sentinel, and the signal-return decision maps that to EINTR when a handler ran and to a restart when none did; both links are hosted-tested. The only path returning 0 is a deadline that has already passed, which is the reference's answer too. Treat the guest differential as a measurement fault until re-run. |
| 471 | slot previously called sched_yield | Closed; the slot is a read-and-clear as the reference specifies. |
