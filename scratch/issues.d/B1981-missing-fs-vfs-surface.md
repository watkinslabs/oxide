| OPEN | MISSING | med | **tmpfs quota is parsed and refused-outside-the-initial-user-namespace, but nothing enforces it.** The `quota`/`usrquota`/`grpquota` classes and the four `*_hardlimit=` values are validated and recorded on the superblock; no charge consults them. The blocker is ownership, not the limits: there is no dquot path for tmpfs and the charge points are owner-less — the page charge takes only the superblock and the file data carries no uid/gid — so closing it means threading per-owner accounting through the block and inode charges plus a charge transfer on `chown`. | B1981. `fs/src/tmpfs/mount_opts/limits.rs`; the limits are read by the admission tests only. | unowned |
| OPEN | MISSING | med | **tmpfs `casefold`/`strict_encoding` are refused where the reference accepts them.** Refusing is honest today — there is no Unicode case-folding table anywhere in the tree, so a mount that asked for case-insensitive lookup would not get one — but a reference kernel built with Unicode support mounts it. Closing it means a case-folding table and a dentry-comparison hook that consults it. | B1981. `fs/src/tmpfs/mount_opts/parse.rs` refuses both names; grep for a folding table returns nothing. | unowned |
