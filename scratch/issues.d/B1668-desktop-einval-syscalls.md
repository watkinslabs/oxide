| NOT-A-DEFECT B1668 | med | Curated `## Desktop` row "`timerfd_settime` returns EINVAL to gnome-shell for `flags=3` (`TFD_TIMER_ABSTIME\|TFD_TIMER_CANCEL_ON_SET`)" is closed — the flag pair is NOT what we reject. `TFD_SETTIME_FLAGS` is exactly that pair, `timerfd_settime` admits it end to end, and `TFD_TIMER_CANCEL_ON_SET` is fully implemented (realtime-generation watcher, `ECANCELED` on read / on re-arm / on `TFD_IOC_SET_TICKS`, wall-step reprojection).
