# B1970 — filesystem PARTIAL rows

Lane: `B1970-vfs-partial-rows-fs`. Scope: the filesystem `PARTIAL` rows of
`scratch/syscall-compliance-matrix.md`.

The dominant finding is the one the brief predicted: the matrix runs
stale-pessimistic. Several rows named gaps that were already closed, two named
a divergence that does not exist in the reference at all, and one named the
wrong reference contract. Corrections are recorded here as first-class results
alongside the implementations.
