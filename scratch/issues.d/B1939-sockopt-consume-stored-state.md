## Matrix rows 54/55 were substantially STALE — disproved claims

Re-verified against current code before implementing. These were listed as open
blockers and are already closed; the row text has been corrected.

| Claimed gap | Reality |
|---|---|
| `IP_PROTOCOL` missing on the set path, "settable on raw sockets" | **The claim is wrong about the reference, not about us.** The reference has no `IP_PROTOCOL` arm in either the IP-level or the raw-socket setsockopt path; it is a send-side control message and a getsockopt only. `sol_ip/set.rs` returning `ENOPROTOOPT` is correct, `sol_ip/get.rs` reads it back, and the control-message form is already parsed with its 1..255 screen. Nothing to fix. |
| `IPV6_JOIN_ANYCAST` / `IPV6_LEAVE_ANYCAST` "declared in uapi with no set-path arm" | Fully implemented in `net::sock_anycast` and reached from `054_setsockopt/ipv6.rs`: device-reference acquire/release, prefix-on-interface screen, multicast/unspecified and locally-owned-address rejection, wildcard-ifindex leave, and release at final close. Carries two ungated tests. |
| TCP fast-open "has no production caller; `syn_options` hardcodes `fastopen: None`" | Closed. `tcp_conn::segment::syn_options` reads the live `fastopen_opt`; the listener validates and mints cookies through `stack::tcp_fastopen` over `tcp_fastopen::decide_counted`, sets `fastopen_child`, and the client learns/blackholes via `tcp_conn::active_fastopen`. |
| IPv6 sticky extension headers "validated hard then never emitted" | Closed. `merge_sticky_raw6_control` calls `merge_sticky_headers`, and the transmit path carries them. |
| `IPV6_PKTINFO` sticky "has NO reader at all, not even getsockopt" | Wrong twice over: `sol_ipv6/get.rs` reads it back and `sock_v6.rs` consumes it for source selection. |
| TCP "does not emit IP_OPTIONS — passes a literal `None`" | Closed. `send_tcp_segment_in` passes `policy.ipv4_options()`. |
| `IP_RETOPTS` "echoes while nothing fills record-route or timestamp on receive" | Closed. `ipv4_options::rx` fills record-route slots and all three timestamp flavours, including the overflow counter, with tests. |
| `IPV6_ROUTER_ALERT` "join bookkeeping without delivery, unlike v4" and `IPV6_ROUTER_ALERT_ISOLATE` "constant with no consumer" | Both closed. `router_alert::v6_deliver` runs on the real forwarding path and `router_alert_matches` applies the selector, the bound device and the isolate rule. |
| `IPV6_USE_MIN_MTU` stored-but-unconsumed | Not stored at all, and correctly so: the reference has no such option: `ENOPROTOOPT` matches. |
| `IP_NODEFRAG`, `IP_RECVERR_RFC4884`, `IP_UNICAST_IF`, `IPV6_ADDR_PREFERENCES`, `IPV6_AUTOFLOWLABEL`, `IPV6_MTU`, `IPV6_UNICAST_IF` stored-but-unconsumed | All consumed: defrag admission, error-queue extension publishing, egress interface selection, source-address preferences, flow-label generation and fragment sizing respectively. |
| `PACKET_COPY_THRESH`, `PACKET_TX_HAS_OFF`, `PACKET_QDISC_BYPASS` stored-but-unconsumed | All consumed: `packet_ring_v12` snaplen copy decision, `packet_ring_tx` frame offset, `packet_tx` transmit path. |
| `SO_NO_CHECK` "has zero consumers" | Consumed on both UDP transmit paths. |
