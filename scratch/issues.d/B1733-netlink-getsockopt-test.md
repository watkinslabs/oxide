| FIXED (this PR) | COVERAGE | high | **`netlink_getsockopt_imports_optlen_before_dispatch_or_value_copyout` failed on `main` against correct code, so the whole `syscalls` suite was red and therefore unread.** The test asserts a source-text ordering using `str::find`, which returns the FIRST occurrence. `netlink_getsockopt` has TWO copy-out sites — the `SOL_SOCKET` fast path returns before the option dispatch, and the dispatch tail — so `find` matched the earlier one and the assertion `dispatch < value` compared the dispatch against a copy-out that legitimately precedes it. The ordering the test exists to protect was never violated: `optlen` is imported (202), screened (206), and only then dispatched (220). An ordering test written against one `find` silently describes whichever site happens to appear first, so adding a legitimate earlier site broke it. Rewritten to check EVERY copy-out site, and to assert the two orderings that carry the invariant rather than a chain that includes an accidental one. | Before: `1 failed`, `assertion failed: import < negative && negative < dispatch && dispatch < value`, reproducible in the main tree in isolation and in the suite. After: `cargo test -p syscalls` 1209 passed / 0 failed.
