# f2fs completeness audit vs reference

Reference: Linux 7.2.0-rc4 (`../reference/Makefile`, confirmed `VERSION=7 PATCHLEVEL=2 SUBLEVEL=0 EXTRAVERSION=-rc4`). Ours: `crates/kernel/f2fs/src/`. Method: enumerated `../reference/fs/f2fs/*` file-by-file plus `sysfs.c` attrs, `include/uapi/linux/f2fs.h` ioctls, `super.c` mount-option table, `f2fs_fs.h`/`f2fs.h` feature bits, fault-injection enum — via 4 parallel read-only sub-agents, each required to cite a call site outside the defining file/tests for anything marked PRESENT.

Excluded from scoring (5 lanes live elsewhere): compressed-writeback deferral, `vfs::AddressSpaceOps`/mmap, readahead, node-writeback-keep-clean + flush-pass bound, quota-dquot-up-front + verity-info-at-open. Marked IN-FLIGHT below where hit.
